개발 플러그인 / DB 어댑터 테스트

호스트 DB가 나니카 데이터 계약을 돌려줄 수 있는지 확인합니다.

이 화면은 개발용 확인 도구입니다. 입력한 DB 정보는 저장하지 않고 서버 API에 한 번만 전달합니다. 통신 테스트는 Supabase REST 접근만 확인하고, SQL/View 테스트는 나니카가 요구하는 view 계약을 확인합니다.

연결 정보

운영 서비스에서는 service role key를 브라우저에 노출하지 마세요. 이 페이지는 로컬 devtools 또는 접근 제한된 관리자 환경에서만 사용하세요.

초기 세팅 적용

나니카 PostgreSQL/Supabase 예시 schema와 현재 generated seed를 적용합니다. 같은 id의 나니카 데이터는 초기 seed 기준으로 덮어써질 수 있으니 로컬 또는 제한된 관리자 환경에서만 실행하세요.

테스트 결과

통신 테스트가 실패하면 URL, API Key, 네트워크 접근을 먼저 확인하세요. SQL/View 테스트 실패 항목은 schema 적용, view 생성, RLS/API key 설정을 확인하세요.

Host 연결 예시

const adapter = createSupabaseNanikaDataAdapter({ supabase });
const mappings = await adapter.list("mappings");
const menus = await adapter.list("menus");
