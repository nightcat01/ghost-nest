제작 홈

이 단계에서 하는 일

표정 이름에 기본 이미지 후보를 묶습니다. 여러 장을 선택하면 같은 표정 안에서 랜덤 후보로 쓸 수 있어요.

  1. 캐릭터를 선택합니다.
  2. 표정 이름을 고르거나 새로 만듭니다.
  3. 이 표정에 사용할 기본 이미지 후보를 선택합니다.
  4. 미리보기를 확인하고 저장합니다.
저장 결과 assets.expressions에 표정 후보가 저장됩니다.
다음 사용처 캐릭터 상태에서 실제 표시 기준으로 사용합니다.
매핑 기준 change_expression 액션에서 선택할 수 있는 재료가 됩니다.

표정 이미지를 저장할 캐릭터를 선택합니다.

표정과 이미지 후보

여기서 고른 이미지는 다음 단계에서 캐릭터 상태의 기준 이미지가 됩니다.

이미지 등록

새 이미지를 바로 캐릭터 에셋 폴더에 저장합니다. 표정은 기본 이미지 후보만 다루고, 여러 이미지를 묶은 기준 화면은 다음 단계의 장면 조합에서 선택합니다.

저장

선택한 기본 이미지 목록을 캐릭터의 표정 후보로 저장합니다. 무대나 장면 조합은 표정 후보에 섞지 않습니다.
