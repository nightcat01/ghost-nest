캐릭터 상태 만들기

제작 홈

이 단계에서 하는 일

표정 이미지 후보 중 실제로 사용할 기본 이미지 한 장을 고르거나, 캐릭터를 포함한 장면 조합을 골라 기준 상태를 만듭니다. 파츠와 애니메이션은 이 상태 위에 붙습니다.

  1. 캐릭터를 선택합니다.
  2. 상태 ID를 정합니다. 처음이면 0으로 두어도 됩니다.
  3. 연결할 표정과 기준 화면을 고릅니다.
  4. 미리보기를 확인하고 저장합니다.
저장 결과 assets.surfaces에 실제 표시 상태가 저장됩니다.
다음 사용처 파츠 움직임은 선택한 캐릭터 상태 위에만 붙어서 움직입니다.
매핑 기준 캐릭터 상태 변경 액션에서 화면에 보여줄 상태로 선택됩니다.

캐릭터

상태를 저장할 캐릭터를 선택합니다.

상태 기본 정보

상태는 표정, 기준 화면, 이후 붙일 파츠를 묶는 단위입니다.

기준 화면 - 기본 이미지

선택한 표정에 등록된 기본 이미지 후보 중 하나를 상태의 기준 화면으로 사용합니다. 장면 조합을 선택하면 기본 이미지는 자동으로 비워집니다.

기준 화면 - 장면 조합

캐릭터가 포함된 저장 조합을 한 장짜리 기준 화면처럼 사용할 수 있습니다. 런타임 배경으로 쓰는 무대 조합과 다르게, 이 값은 캐릭터 상태 안에서만 쓰입니다.

저장

캐릭터 상태를 저장하면 다음 단계에서 눈, 입, 장식 같은 파츠를 이 상태 위에 추가할 수 있습니다.
