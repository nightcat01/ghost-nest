상태 연결하기

제작 홈

이 단계에서 하는 일

표정 만들기와 무대 조합 만들기에서 준비한 재료를 런타임 표시 상태에 연결합니다. 여기서는 새 재료를 만드는 대신, 이미 만든 표정·기본 이미지·무대 조합 중 무엇을 보여줄지 정합니다.

  1. 캐릭터를 선택합니다.
  2. 상태 저장 키를 고릅니다. 처음이면 자동 추천값을 그대로 써도 됩니다.
  3. 이미 만든 표정과 기준 화면을 고릅니다.
  4. 미리보기를 확인하고 저장합니다.
저장 결과 assets.surfaces에 실제 표시 상태 연결이 저장됩니다.
다음 사용처 파츠 움직임은 선택한 상태 연결 위에만 붙어서 움직입니다.
매핑 기준 상태 변경 액션에서 화면에 보여줄 표시 상태로 선택됩니다.

캐릭터

상태 연결을 저장할 캐릭터를 선택합니다.

연결할 표시 상태

표시 상태는 런타임에서 바뀌는 화면 단위입니다. 표정 이름과 실제로 보여줄 기준 화면을 연결합니다.

상태 저장 키는 런타임이 화면을 바꿀 때 찾는 이름입니다. 숫자만 쓸 필요는 없고, 기존 키를 고르면 해당 상태를 수정합니다.

기준 화면 - 기본 이미지

표정 만들기에서 등록한 기본 이미지 후보 중 하나를 기준 화면으로 연결합니다. 무대 조합을 선택하면 기본 이미지는 자동으로 비워집니다.

기준 화면 - 무대 조합

저장된 무대 조합을 기준 화면으로 연결할 수 있습니다. 이 값은 전체 배경 설정이 아니라, 선택한 표시 상태에서 보여줄 화면 재료입니다.

저장

상태 연결을 저장하면 다음 단계에서 눈, 입, 장식 같은 파츠를 이 표시 상태 위에 추가할 수 있습니다.
