기능 연결 작업판

런타임에서 실제 캐릭터로 들어가고, 캐릭터가 가진 재료와 이벤트, 액션을 노드로 이어 붙입니다.

현재 연결 현황

나니카가 가진 캐릭터, 기능, 이벤트, 액션이 어느 정도 연결되어 있는지 먼저 확인합니다.

연결 지도

runtime에서 캐릭터, 대사, UI, 플러그인 기능이 실행 규칙으로 어떻게 이어지는지 요약합니다.

흐름 보드

시작점부터 이벤트, 저장된 연결, 실행 액션, 기능 묶음까지 한 줄기처럼 확인합니다.

재료 지도

대사, scene, surface, 플러그인처럼 반복해서 사용할 수 있는 재료와 반드시 연결되어야 하는 입력을 구분합니다.

연결 안 된 항목

아직 실행 규칙에 사용되지 않은 이벤트와 동작입니다. 필요한 항목은 새 연결 만들기에서 연결합니다.

적용된 실행 규칙

현재 preset에 실제로 들어간 실행 규칙입니다. 저장만 된 연결과는 구분됩니다.

보조 전체 그래프

작업판에서 다루는 전체 구조를 한 번에 훑어보는 보조 화면입니다. 실제 편집은 위 작업판에서 진행합니다.
