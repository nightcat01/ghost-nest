캐릭터 설정

캐릭터

설정을 읽고 저장할 캐릭터 폴더를 선택합니다.

1. 표정 랜덤 이미지

표정 이름이 먼저 기본 이미지 후보를 고릅니다. 캐릭터 상태의 기본 이미지는 이 후보 안에 있어야 파츠까지 이어집니다.

2. 캐릭터 상태 기본 구성

표정이 선택한 특정 기본 이미지에 붙을 조합 단위입니다. 캐릭터 상태 아래에 눈, 입, 소품 같은 파츠가 추가됩니다.

3. 상태 기준 이미지

이 캐릭터 상태의 기준 이미지입니다. 위에서 선택한 표정의 랜덤 이미지 후보 중 하나와 같아야 합니다.

4. 저장

표정 이미지 묶음과 캐릭터 상태 기본 구성을 각각 저장합니다. 파츠는 이 상태가 정상 저장된 뒤 파츠 만들기에서 붙입니다.

캐릭터 상태와 표정을 조합할 준비가 됐어요.
