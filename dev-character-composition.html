캐릭터 설정

캐릭터

설정을 읽고 저장할 캐릭터를 선택합니다.

1. 표정 후보 이미지

표정 이름에 여러 기본 이미지 후보를 묶습니다. 상태 연결에서 고르는 기준 이미지는 이 후보 안에 있어야 파츠까지 이어집니다.

2. 상태 연결 기본 구성

표정과 기준 화면을 런타임에서 바꿀 수 있는 상태 저장 키에 연결합니다. 이 상태 아래에 눈, 입, 소품 같은 파츠가 추가됩니다.

3. 기준 화면

이 상태 연결에서 실제로 보여줄 기준 이미지입니다. 위에서 선택한 표정 후보 중 하나와 같아야 합니다.

4. 저장

표정 후보와 상태 연결 기본 구성을 각각 저장합니다. 파츠는 이 상태 연결이 저장된 뒤 파츠 움직임 만들기에서 붙입니다.

상태 연결과 표정을 조합할 준비가 됐어요.
