파츠 움직임 만들기

제작 홈

이 단계에서 하는 일

상태 연결 위에 눈 깜빡임, 말할 때 입모양, 장식 같은 파츠 움직임을 얹습니다. 먼저 저장된 상태 연결을 고른 뒤, 파츠 이미지와 위치를 정하세요.

  1. 캐릭터와 상태 연결을 선택합니다.
  2. 파츠 종류와 저장 이름을 고릅니다.
  3. 이미지 프레임과 위치를 오른쪽 작업판에서 확인합니다.
  4. 저장해서 해당 상태에 파츠를 붙입니다.
저장 결과 선택한 상태 연결 안에 파츠와 애니메이션이 저장됩니다.
동작 범위 입모양, 눈깜빡임은 연결한 상태 연결에서만 실행됩니다.
매핑 기준 기능 연결에서 특정 파츠를 실행하는 액션으로 사용할 수 있습니다.

파츠를 붙일 상태 선택

표정과 기본 이미지가 연결된 상태 연결을 고른 뒤, 그 상태에서만 동작할 파츠를 만듭니다.

저장 경로

이미지를 저장하거나 불러올 폴더입니다. 파츠 편집에서는 무대 조합을 직접 다루지 않습니다.

이미지와 프레임 조정

기본 이미지와 파츠 이미지를 고르고, 프레임 순서와 영역 값을 조정합니다. 오른쪽 작업판은 결과를 크게 확인하고 위치를 드래그하는 영역입니다.

영역 선택에서 잡은 위치 값은 기준 이미지 위에 파츠가 실제로 배치될 위치입니다.

재생과 저장

프레임 동작과 확대 비율을 확인한 뒤, 선택한 상태 연결에 파츠 설정을 저장합니다.
