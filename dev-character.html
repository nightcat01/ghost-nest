캐릭터 설정 플러그인

제작 홈

플러그인 목록

왼쪽에서 오른쪽으로 캐릭터 설정을 완성합니다

캐릭터를 만들고, 표정과 상태를 준비한 뒤, 필요한 파츠 움직임과 무대 조합을 붙입니다. 기능 연결과 런타임 테스트는 이 화면의 제작 순서에 포함하지 않고, 설정이 끝난 뒤 별도 도구에서 진행합니다.

새 캐릭터 만들기

제작 상태를 확인하는 중입니다.

1. 캐릭터 만들기 작업 기준이 되는 캐릭터 폴더와 기본 설정을 준비합니다.
2. 표정과 상태 표정 후보를 만들고 런타임에서 실제로 보일 상태 연결로 묶습니다.
3. 파츠와 무대 움직이는 파츠와 배경/소품 조합을 상태 연결 주변에 붙입니다.
4. 별도 도구로 이동 캐릭터 설정을 마친 뒤 기능 연결 도구나 런타임 테스트로 넘어갑니다.
표정 neutral, happy처럼 사용자가 이해하는 표정 이름과 기본 이미지 후보를 묶습니다.
상태 연결 런타임에서 실제로 표시되는 중심 단위입니다. 표정, 기본 이미지, 조합 이미지를 포함할 수 있습니다.
파츠 움직임 눈 깜빡임, 입모양처럼 특정 상태 연결 위에서 움직이는 보조 이미지 묶음입니다.
무대 조합 배경, 책상, 소품, FX를 캐릭터 주변에 배치한 이미지 그룹입니다.
다음 도구 기능 연결과 런타임 테스트는 캐릭터 설정 밖에서 캐릭터 결과물을 가져다 씁니다.
작업 경로 / 접근 설정

npm으로 설치해 다른 프로젝트에서 사용할 때도 실제 캐릭터와 공통 에셋 폴더를 지정해서 씁니다.

작업 경로를 불러오는 중입니다.

현재 상태

선택한 캐릭터가 재료, 표정, 상태 연결, 파츠 움직임, 무대 조합까지 어느 정도 준비됐는지 보여줍니다.

다음 작업

캐릭터 설정 안에서 할 일과, 설정 후 별도 도구에서 할 일을 분리해서 보여줍니다. 캐릭터가 필요한 작업은 캐릭터 선택 전까지 잠김 상태로 표시됩니다.
