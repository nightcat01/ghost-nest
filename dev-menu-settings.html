메뉴 설정

플러그인 목록
개발 플러그인 / 메뉴 설정

말풍선이나 패널에 띄울 메뉴 묶음을 만듭니다.

메뉴는 사용자가 누를 선택지와 실행 액션을 모아 둔 재료입니다. 저장한 메뉴는 매핑에서 menuId로 불러와 말풍선이나 고정 패널 영역에 띄울 수 있습니다.

템플릿

메뉴는 캐릭터와 분리된 공통 재료입니다. 캐릭터, 이벤트, 조건과의 연결은 매핑 설정에서 처리합니다.

메뉴 세트

저장될 메뉴 묶음의 이름과 기본 표시 방식을 정합니다.

메뉴 트리

항목을 선택해서 수정하거나 하위 메뉴를 추가합니다. 이동 메뉴는 action JSON에 navigate를 넣으면 됩니다.

메뉴 설정을 불러오는 중입니다.

항목 편집

선택된 항목이 없습니다.

메뉴 항목은 ID, 화면에 보일 라벨, 눌렀을 때 실행할 액션으로 구성됩니다. ID는 저장용 이름이고, 사용자는 라벨과 설명만 보게 됩니다.

기능 추가

메뉴 항목을 눌렀을 때 실행할 기능을 고르고 필요한 값을 입력합니다.
