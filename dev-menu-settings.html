메뉴 설정

플러그인 목록
개발 플러그인 / 메뉴 설정

말풍선이나 패널에 띄울 메뉴 묶음을 확인합니다.

메뉴는 런타임 액션을 모아 둔 선택지입니다. 사용자 메뉴, 개발자 메뉴, 전체 데모 메뉴를 나눠서 보고 매핑 화면이나 호스트 앱에서 사용할 JSON 초안으로 복사할 수 있습니다.

기준 캐릭터

캐릭터별 표정, surface, scene 메뉴가 포함되는지 확인하려면 캐릭터를 선택합니다.

메뉴 종류

메뉴 트리

각 카드는 실제 메뉴 항목입니다. 하위 메뉴와 실행 액션 수를 함께 보여줍니다.

메뉴 설정을 불러오는 중입니다.

저장/매핑용 JSON

지금은 메뉴를 직접 파일로 저장하지 않고, 매핑이나 호스트 앱 설정에 넣을 수 있는 초안을 확인합니다.
