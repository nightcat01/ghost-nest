메뉴 설정

메뉴는 런타임에서 불러올 재료입니다. 여기서는 메뉴 묶음과 항목, 실행 기능만 만들고 실제 사용처는 매핑에서 연결합니다.

플러그인 목록
개발 플러그인 / 메뉴 설정

저장

저장 후 매핑에서 이 메뉴 ID를 선택해 사용할 수 있습니다.

메뉴 설정을 불러오는 중입니다.

1. 메뉴 선택 템플릿이나 저장 메뉴를 불러오고 기본 정보를 정합니다.
2. 항목 편집 항목을 추가하고 눌렀을 때 실행할 기능을 붙입니다.
3. 트리 확인 사용자에게 보일 메뉴 구조를 확인하고 저장합니다.
선택한 시작 재료 아직 선택되지 않았어요.
메뉴 기본 정보 메뉴 이름과 표시 방식을 정하세요.

시작 재료

메뉴는 캐릭터와 분리된 공통 재료입니다. 캐릭터, 이벤트, 조건과의 연결은 매핑 설정에서 처리합니다.

저장된 메뉴

기존 메뉴를 불러와 수정하거나 복제해서 새 메뉴로 저장합니다.

메뉴 정보

저장될 메뉴 묶음의 이름과 기본 표시 방식을 정합니다.

항목 트리

항목 편집

선택된 항목이 없습니다.

메뉴 항목은 ID, 화면에 보일 라벨, 눌렀을 때 실행할 액션으로 구성됩니다. ID는 저장용 이름이고, 사용자는 라벨과 설명만 보게 됩니다.
